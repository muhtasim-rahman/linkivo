Keyboard shortcuts

Press ? on most pages to see the list for that page.

1Common

  • Ctrl or Cmd + K: search.
  • / : focus the page's search field.
  • N: new folder (Library). A: add a link. I: import.
  • Esc: close a popup or leave selection.
